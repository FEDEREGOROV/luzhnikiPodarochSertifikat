# Подарочные сертификаты Аквакомплекса «Лужники»

Локальный адаптивный прототип страницы продажи подарочных сертификатов.

## Запуск

Откройте терминал в этой папке и выполните:

```bash
python3 -m http.server 4173
```

Затем откройте [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Что реализовано

- 12 актуальных сертификатов и цен с официального сайта;
- пошаговый выбор: формат отдыха → 4 подходящих сертификата → оплата;
- официальный логотип Аквакомплекса из фирменного SVG-спрайта;
- выбор сертификата и закрепленная панель заказа;
- официальный платежный виджет в модальном окне;
- запасная ссылка на отдельную страницу оплаты;
- адаптивная версия для телефона;
- доступная клавиатурная навигация и reduced-motion режим.

## Файлы

- `index.html` — структура и контент;
- `styles.css` — визуальная система и адаптивность;
- `script.js` — каталог, фильтры и платежный сценарий.

Цены отмечены датой проверки — 27 октября 2026 года. Итоговая стоимость всегда подтверждается в официальном платежном виджете.
